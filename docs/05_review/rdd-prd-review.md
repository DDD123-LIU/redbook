## 非阻塞问题与方案边界
- 95% 是用户要求的样本验收阈值，不是统计学上未来必然准确的证明；保持分母、样本量和覆盖情况可查。
- 无反馈的真实原因可能未知。需检查事件和保存链路，不能凭模型推断用户没点。
- 全量收藏不完整不能误判取消。内容不可访问和平台限制需在验证报告中列出。
- 不自动新增长期兴趣、不自动停推、不改额度和费用边界。
- Git 按阶段提交，真实账号数据、Cookie、密钥不得写入基线。
