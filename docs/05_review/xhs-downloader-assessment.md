## 收藏入口确实存在
[用户脚本](https://github.com/JoeanAmier/XHS-Downloader/blob/3261312721f0b37c705ba6515885bc7f34349f2f/static/XHS-Downloader.js) 2911—2914行把收藏菜单关联到 extractAllLinksEvent(1)。1063—1067行从网页 user.notes._rawValue[order] 取笔记，提取ID、token、封面、作者和标题。1105—1107行生成带 xsec_token 的链接，1154—1163行复制到剪贴板。
这是实质性新增候选能力，比仅有搜索/详情更贴近收藏输入。但须在已加载收藏的页面运行；菜单存在不代表正确页签和全部数据均已加载。

当前提取字段无本人收藏时间。页面内存是否保留全部5000+记录、异常页是否被跳过、长时间滚动是否失效均未知。

## 程序接口可以复用，但不负责列出收藏
[app.py](https://github.com/JoeanAmier/XHS-Downloader/blob/3261312721f0b37c705ba6515885bc7f34349f2f/source/application/app.py) 提供 POST /xhs/detail，以及 MCP get_detail_data / download_detail。输入是作品链接；未在这些接口中见收藏列表端点。不能把 MCP 接通等同收藏同步完成。
Python extract 返回 list[dict]，详情获取与文件下载可分开。MCP download_detail 默认不返回数据，若要下载后取得信息须明确 return_data。MCP处理路径使用 check_record=True，需验证已下载记录是否影响后续详情刷新。下载记录不能充当收藏快照。
[请求/响应模型](https://github.com/JoeanAmier/XHS-Downloader/blob/3261312721f0b37c705ba6515885bc7f34349f2f/source/module/model.py) 包括 url、download、index、cookie、proxy、check_record；响应有message、params、data。若传入cookie，响应模型存在params字段，因此实测前须检查实际响应是否回显凭据，不直接把原响应保存入Git或报告。

## 正文与时间字段
[explore.py](https://github.com/JoeanAmier/XHS-Downloader/blob/3261312721f0b37c705ba6515885bc7f34349f2f/source/application/explore.py) 映射作品ID、标题、描述、标签、作者及互动数量，时间来自帖子time/lastUpdateTime。发布时间不能当收藏时间；收藏数量是互动统计，不能当本账号收藏总数。
导出的作品链接在此处只含ID，未保留输入token；集成时须保留原始带token入口，不能只存导出链接。时间字符串使用本机时间转换，后续必须保留原始时间戳并明确时区。
媒体下载能力有公开说明，但本轮未验证原图、图片顺序、缺图、视频封面与飞书显示。支持下载不等于B样式通过。

不改写上游采集器，不加入自动化规避手段。若现有工具不足，报告限制或换既有生态路线。
