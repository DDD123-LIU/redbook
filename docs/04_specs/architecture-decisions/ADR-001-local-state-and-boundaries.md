## 决策提案

使用已可运行的Node24标准库node:sqlite，单本地库、单业务执行槽、普通函数边界。来源和模型继续调用现有工具。媒体保存在Git外文件区，库记录版本及hash。不要把每个概念实体扩展成独立服务或插件。

发送意图先事务保存，再调用外部。成功回执或完整唯一查询才归账；超时/崩溃unknown不能盲重发。反馈事件、当前值、历史及回执待办同事务保存，保存后回执。执行槽没有超时自动抢占；确认旧执行者终止并核对在途后才恢复。
