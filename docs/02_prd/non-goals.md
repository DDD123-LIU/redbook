# 非目标与范围边界
日期：2026-10-14。执行者：Codex。版本：v0.1。状态：随 PRD 基线确认。

## 首期不做
推特或多平台扩展、旧收藏重新投递、多用户运营、商业付费订阅、独立社区、发帖评论或在小红书代点赞。
不强制用户填写偏好问卷、逐条解释取消收藏、审批分类和算法权重。
不启动即探索、不无限连续推送、不跨天累加欠额。
不默认给 AI 摘要或理由，不用模板占位和无价值重复内容凑数。
不通过付费 API 做 AI 分析筛选，不自动增购额度。
不宣称本地关机仍能准点运行，不把来源读取成功当品味验收通过。

## 容易误加的行为
用户在飞书“赞”是推荐评价，不代表向小红书发送点赞操作。
陌生探索获赞不等于自动新增为长期关注；仍需确认或用户明确指令。
低于 95% 不默认停推、清空历史或重置测试统计。
改变算法、编号或权重属于系统方案设计；改变数量、费用和质量标准必须有明确需求依据。
新增用户需求以最新明确指令为准，更新范围后再实现，不机械拒绝用户后续改动。
